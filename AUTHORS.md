# Authors of xrdp

xrdp and its auxuary softwares are originally devleoped by [Jay Sorg](https://github.com/jsorg71)
and now developed community-driven.

Please note that not all contributors are on the list.  If you think you made
significant contribution to xrdp, feel free to make a pull request to add
yourself to the contributors list.
